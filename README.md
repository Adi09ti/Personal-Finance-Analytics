# Personal Finance Analytics Dashboard

## Project Overview
Analysis of 3,000 customer financial records to understand 
income patterns, spending behaviour, fraud risk, and 
financial stress across different economic scenarios.

## Tools Used
- Microsoft Excel (Advanced)
- Pivot Tables
- VLOOKUP
- Nested IF Statements
- Conditional Formatting
- Interactive Dashboard

## Key Findings
1. Employment type does not significantly affect income levels
   — Freelance, Mixed, and Salary customers earn similarly 
   around ₹4,000/month

2. Spending is distributed equally across all categories
   — difference between highest and lowest category is 
   only ₹147

3. Financial stress remains consistent across inflation, 
   recession, and normal economic scenarios — suggesting 
   individual behaviour drives stress more than 
   external conditions

## Dataset
3,000 customer records with 25 variables including income,
expenses, savings, credit score, debt ratio, fraud flags,
and financial stress levels across 2019-2023.

- personal_finance_tracker_dataset.csv — Raw dataset
